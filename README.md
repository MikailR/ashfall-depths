# Ashfall Depths — hosted demo

Mobile-first, first-person grid dungeon crawler demo (Eye of the Beholder / Lands of Lore style UI).

**Play it on your phone:** https://mikailr.github.io/ashfall-depths/

This repository only hosts the production build. The `gh-pages` branch holds the static site
(`index.html` + inlined assets) and `.github/workflows/deploy.yml` publishes it to GitHub Pages.
The game source (Vite + React + TypeScript) lives in the project repository.

Tips on a phone: use *Add to Home Screen* for a chrome-less fullscreen experience; tap portraits’
weapon/skill icons to attack, hold the D-pad to keep walking.
